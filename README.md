# 탄벌초 얼음땡 V16

AWS Lightsail에서 운영하는 실시간 온라인 얼음땡 웹게임입니다.

## V16 추가 기능

### 학생 실시간 채팅
- 학생 게임 화면 오른쪽의 작은 `💬 실시간 채팅창`에서 서로 메시지를 보낼 수 있습니다.
- 메시지는 최대 60자입니다.
- 도배 방지를 위해 학생 1명당 5초에 한 번만 전송할 수 있습니다.
- 제한은 서버에서도 검사하므로 빠르게 반복 클릭하거나 새로고침해도 연속 전송할 수 없습니다.
- 전송 후 버튼에 남은 대기시간이 표시됩니다.
- 채팅을 입력하는 동안 WASD/방향키가 게임 이동으로 작동하지 않습니다.
- 교사 화면의 실시간 기록에서도 학생 채팅을 확인할 수 있습니다.

## 이전 주요 기능
- 최대 100명 실시간 접속 구조
- 운동장 + 본관 1~2층
- QR/방 코드 학생 입장
- 술래/도망팀 분리 시작 및 술래 10초 지연 출발
- 얼음, 구조, 유령 이동, SOS 제한
- 점프, 붕어빵, 부스터
- 게임 중간 붕어빵 1회 등장 및 20초 유지
- 누적 승리 포인트 및 라운드 MVP
- 교사 전체 속도 UP 이벤트
- 교사 전체 위치 5초 공개 이벤트
- 교사 맵 확대/축소 및 드래그
- 게임 종료 30초 전 알림
- 모바일/태블릿 가상 조이스틱

## Lightsail 업데이트
GitHub에 새 버전을 올린 뒤 Lightsail SSH에서 기존 프로젝트 폴더로 이동해 아래 명령을 실행합니다.

```bash
git pull origin main
npm install
pm2 restart all
```

PM2 프로세스 구성이 바뀐 경우에만 필요하면 `pm2 save`를 실행합니다.
