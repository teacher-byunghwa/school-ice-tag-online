# 탄벌초 얼음땡 V5

GitHub + Render 무료 배포용 실시간 웹게임입니다.

## V5 핵심 변경
- 술래를 검정/보라 계열의 도둑 캐릭터로 완전히 구분
- 학생 입장 직후 대기 중에도 학교 맵과 다른 학생 위치 표시
- 아웃된 학생은 유령이 되어 게임 중 계속 이동 가능
- 마지막 도망팀이 죽어 게임이 끝난 뒤에도 다음 게임 전까지 유령 이동 가능
- 살아남은 도망팀이 전부 얼면 즉시 술래팀 승리
- 교사 화면에 현재 얼음 인원 표시
- 얼음/아웃/구출 소식은 전체 팝업이 아니라 실시간 채팅창에만 표시
- 게임 시작/게임 종료만 큰 안내 화면 유지

## 기존 기능
- 최대 100명 구조
- 교사용 방 만들기 + QR 학생 입장
- 운동장 + 본관 1~3층
- 남녀 교복 캐릭터
- 휴대폰 화면 꺼짐 후 재접속 복구
- 점프 / 붕어빵 / 10초 부스터
- 술래와 도망팀 모두 붕어빵 부스터 사용
- 얼음 상태에서 같은 팀에게 위치 구조 요청

## 실행
```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속
