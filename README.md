# 탄벌초 얼음땡 V10

GitHub + Render Free 배포용 실시간 온라인 얼음땡 게임입니다.

## V10 추가 기능
- 게임 시작 시 10초 동안 전체 팀 명단 공개
  - `술래팀: 이름들`
  - `도망팀: 이름들`
  - 자기 팀도 함께 강조
- 팀 공개 10초 동안은 실제 이동/점프/얼음/부스터가 시작되지 않으며, 10초 후 게임 시간이 정상적으로 시작됨
- 같은 방에서 여러 게임을 하면 누적 개인 포인트 유지
- 각 게임 승리팀 소속 전원에게 +1포인트
- 교사 화면에서 누적 포인트 순위표 상시 확인
- 학생 화면 상단에서 자기 누적 포인트 상시 확인
- 다음 게임 준비/초기화를 해도 포인트는 유지됨

## 기존 주요 기능
- 최대 100명 구조
- QR 및 방 코드 학생 입장
- 남/여 교복 캐릭터, 별도 술래 캐릭터
- 운동장 + 본관 1~3층
- 얼음/구출/유령/점프
- 붕어빵 1회 등장 + 20초 유지 + 부스터
- 술래와 도망팀 분리 출발
- 휴대폰 재연결 복구
- 실시간 상태 채팅창

## 로컬 실행
```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속

## Render
`render.yaml`은 Free 플랜(`plan: free`) 기준입니다.
