# 탄벌초 얼음땡 V12

GitHub + Render 무료 배포용 실시간 온라인 얼음땡 게임입니다.

## V12 업데이트
- 게임 종료 30초 전에 모든 참가자와 교사에게 알림
  - 화면을 가리지 않는 상단 알림 배너
  - 효과음과 실시간 채팅창 안내
- 휴대폰/태블릿 이동 조작을 4방향 버튼에서 가상 조이스틱으로 변경
  - 조이스틱을 원하는 방향으로 끌면 이동
  - 대각선 이동 지원
  - 손을 떼면 자동으로 중앙으로 복귀
  - 길게 눌렀을 때 브라우저 선택/복사 메뉴 방지 유지
- 교사용 학생 입장 QR코드를 더 크게 표시
  - QR 이미지 자체도 720px로 생성하여 선명도 향상

## 기존 주요 기능
- 최대 100명 실시간 접속 구조
- 교사 방 만들기 / QR 또는 방 코드로 학생 입장
- 술래·도망팀 자동 배정 및 10초 팀 명단 공개
- 도망팀 선출발, 술래는 실제 게임 시작 후 10초 뒤 출발
- 운동장 + 본관 1~3층
- 점프, 얼음/구출, 유령 이동, SOS 제한
- 게임 중간 붕어빵 1회 등장, 20초 유지, 술래·도망팀 모두 부스터 사용
- 게임별 승리팀 +1점, 방 안에서 개인 포인트 누적
- 교사 지도 마우스 휠 확대/축소 및 드래그 이동
- 게임 종료 교사/학생 빵빠레와 승리 안내

## 로컬 실행
```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속
