# 우리 학교 얼음땡 V2 — 실시간 온라인 웹게임

교사가 방을 만들고 학생들이 QR로 접속해 최대 100명까지 동시에 즐길 수 있는 Socket.IO 기반 실시간 얼음땡 게임입니다.

## V2에서 수정한 점
- **두 번째 학생이 방향키로 움직이지 못하던 문제 수정**
  - V1의 두 번째 시작 위치가 나무 충돌 영역과 겹칠 수 있었습니다.
  - V2는 최대 100개의 시작 위치를 모두 충돌 검사한 뒤 배치합니다.
- 운동장을 1600×900 → **2400×1400**으로 확대
- 학생 화면은 자기 캐릭터를 따라가는 카메라 방식으로 변경
- 원형 말 대신 **머리·몸·팔·다리가 있는 사람 캐릭터** 사용
- 이동 중 팔과 다리가 흔들리는 걷기 애니메이션 추가
- 학교 건물·운동장에 그림자와 깊이감을 넣은 **가벼운 2.5D 스타일** 적용
- 태블릿 방향키를 길게 눌러도 복사/찾아보기/문맥 메뉴가 뜨지 않도록 방지
- 태블릿에서 손가락을 누른 상태가 안정적으로 유지되도록 pointer capture 적용
- 네트워크 위치 업데이트 사이를 부드럽게 보간하여 움직임 개선

## 주요 기능
- 교사용 방 만들기 + 5자리 방 코드
- 학생 입장 QR 자동 생성
- 교사가 술래 수(1~20명)와 게임 시간 설정
- 학생 WASD / 방향키 이동
- `I` 키 또는 화면 얼음 버튼으로 얼음
- 같은 편이 얼음 상태 친구에게 가까이 가면 자동 구출
- 술래가 일반 도망자에게 닿으면 아웃
- 아웃된 위치에 흔적이 남고, 아웃된 학생은 관전
- 교사용 실시간 전체 맵과 접속/생존 인원, 이벤트 로그
- 모바일·태블릿 터치 방향키/얼음 버튼
- 최대 100명 입장 제한

> 현재 규칙은 **고전 얼음땡 방식**으로, 얼음 상태인 학생은 술래에게 잡히지 않습니다.

## 로컬 실행
Node.js 18 이상 필요.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

## Render 무료 배포
`render.yaml`은 `plan: free`로 설정되어 있습니다.

1. GitHub 저장소에 이 폴더의 내용을 업로드
2. Render에서 **New Web Service** 선택
3. GitHub 저장소 연결
4. Instance Type에서 **Free** 확인
5. Build Command: `npm install`
6. Start Command: `npm start`
7. 배포 완료 후 생성된 HTTPS 주소 접속

## 3D에 대해
V2는 50명 이상의 태블릿 동시접속과 무료 Render 환경에서 가볍게 작동하도록 **2.5D Canvas 방식**을 사용합니다. 완전한 3D(Three.js/WebGL) 학교 건물도 만들 수 있지만, 저사양 태블릿에서는 렌더링 부담이 커질 수 있으므로 실제 수업용 첫 버전에는 2.5D가 더 안정적입니다.
