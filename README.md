# 우리 학교 얼음땡 — 실시간 온라인 웹게임

교사가 방을 만들고 학생들이 QR로 접속해 최대 100명까지 동시에 즐길 수 있는 Socket.IO 기반 실시간 얼음땡 게임입니다.

## 구현 기능
- 교사용 방 만들기 + 5자리 방 코드
- 학생 입장 QR 자동 생성
- 교사가 술래 수(1~20명)와 게임 시간 설정
- 학생 WASD / 방향키 이동
- `I` 키 또는 화면 얼음 버튼으로 얼음
- 같은 편이 얼음 상태 친구에게 가까이 가면 자동 구출
- 술래가 일반 도망자에게 닿으면 아웃
- 아웃된 위치에 해골 흔적이 남고, 아웃된 학생은 관전
- 교사용 실시간 맵과 접속/생존 인원, 이벤트 로그
- 모바일 터치 방향키/얼음 버튼
- 최대 100명 입장 제한 (기본 서버 구조는 50명 이상을 염두에 둠)

> 현재 규칙은 **고전 얼음땡 방식**으로, 얼음 상태인 학생은 술래에게 잡히지 않습니다.

## 로컬 실행
Node.js 18 이상 필요.

```bash
npm install
npm start
```
브라우저에서 `http://localhost:3000` 접속.

같은 와이파이에서 시험하려면 서버 PC의 사설 IP로 접속하면 됩니다. 예: `http://192.168.0.10:3000`

## 인터넷 배포
이 프로젝트는 Render/Railway/Fly.io 같은 Node 웹서비스에 그대로 배포할 수 있습니다.

### Render 예시
1. GitHub에 이 폴더를 저장소로 업로드
2. Render에서 **New Web Service** 선택
3. 저장소 연결
4. Build Command: `npm install`
5. Start Command: `npm start`
6. 배포 후 생성된 HTTPS 주소를 교사가 열어 방 생성
7. 학생들은 화면의 QR을 스캔해 접속

50명 이상을 안정적으로 사용하려면 무료 인스턴스보다 유료/상시 실행 인스턴스를 권장합니다.
