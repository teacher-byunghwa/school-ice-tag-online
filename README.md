# 탄벌초 얼음땡 V11

GitHub + Render 무료 배포용 실시간 웹게임입니다.

## V11 변경사항
- 얼음 상태 SOS는 **최근 30초 동안 최대 2회**만 전송 가능
- 2회를 모두 쓰면 SOS 버튼이 남은 대기시간 동안 비활성화됨
- 게임 종료 시 **교사 화면에도 빵빠레 효과음 + 승리팀 팝업** 표시
- `전체 생존`은 **아웃되지 않았고 얼어 있지도 않은 도망팀 인원**만 표시
- 교사 맵에서 **마우스 휠 확대/축소**, 드래그 이동, 더블클릭 초기화 가능
- 팀 공개 10초가 끝난 뒤 도망팀은 즉시 출발, **술래는 추가 10초 후 출발**
- 운동장 → 본관 1층 입구 **3개**, 1층 → 운동장 출구 **3개**
- 1↔2층, 2↔3층 이동 계단을 **좌우 양쪽**에 배치
- 게임 중간에 한 번 나오는 붕어빵 수를 기존의 **2배**로 증가
- 붕어빵은 기존처럼 등장 후 20초 동안만 유지

## 기존 주요 기능
- QR/방코드 학생 입장, 최대 100명 구조
- 남녀 교복 캐릭터, 별도 술래 도둑 캐릭터
- 운동장 + 본관 1~3층
- 얼음/구출/유령/점프/부스터
- 승리팀 개인 누적 포인트
- 팀 전체 명단 10초 공개
- 휴대폰 재접속 복구

## 실행

```bash
npm install
npm start
```
