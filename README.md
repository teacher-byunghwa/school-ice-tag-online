# 탄벌초 얼음땡 V8

무료 GitHub + Render 배포용 실시간 웹게임입니다.

## V8 핵심 수정
- 게임 시작 전에는 학생들이 운동장 중앙 대기 구역에 함께 모임
- 게임 시작과 동시에 역할을 정한 뒤 팀별 출발 위치를 완전히 분리
- 술래는 운동장 서쪽 시작 구역에서 술래끼리 분산 배치
- 도망팀은 운동장 동쪽 시작 구역에서 도망팀끼리 분산 배치
- 두 팀 사이를 약 1,300px 이상 떨어뜨려 시작 직후 바로 잡히는 현상을 완화
- 술래/도망팀이 각각 한 점에 겹치지 않도록 격자형으로 여러 시작점을 사용

## 기존 주요 기능
- 교사용 방 만들기 + 학생용 QR/방 코드 입장
- 최대 100명 동시 접속 구조
- 술래 수 / 게임 시간 설정
- 운동장 + 본관 1~3층 맵
- 남녀 교복 캐릭터, 술래 전용 캐릭터
- 얼음 / 구출 / 아웃 / 유령 이동
- 점프, 붕어빵 1회 등장, 10초 부스터
- 술래도 부스터 사용 가능
- 얼음 상태에서 같은 팀에게 위치 구조 요청
- 실시간 채팅형 게임 알림
- 휴대폰 재접속 복구
