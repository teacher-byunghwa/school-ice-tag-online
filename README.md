# 탄벌초 얼음땡 V7

GitHub + Render 무료 배포용 실시간 웹게임입니다.

## V7 수정사항
- QR 학생 입장 오류 수정
  - QR 링크에 방 코드를 path와 query 두 방식으로 함께 넣음
  - 학생 QR/초대 링크가 교사 세션보다 항상 우선
  - 같은 기기에 이전 게임 참가 기록이 남아 있어도 새 QR 방으로 입장 가능
- 첫 화면에 `학생으로 입장` 버튼 복원
  - 게임 주소만 받은 학생은 방 코드를 직접 입력 가능
- `만든이: 김병화` 표시
  - 첫 화면
  - 학생 닉네임/방 코드 입력 화면
  - 교사 대시보드
- V6의 게임 규칙과 기능은 그대로 유지

## 실행
```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속
