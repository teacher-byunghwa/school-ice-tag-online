# 우리 학교 얼음땡 V3

GitHub + Render 무료 Web Service에서 실행할 수 있는 실시간 멀티플레이 얼음땡 게임입니다.

## V3 추가 기능

- 휴대폰 화면이 꺼져 Socket 연결이 끊겨도 같은 캐릭터/역할/위치로 자동 복귀
- 게임 시작 시 술래 수, 도망팀 수, 내 역할 안내 팝업
- 입장 시 남자/여자 캐릭터 선택
- 시작/얼음/구출/아웃/점프/아이템/부스터/게임 종료 효과음
- 점프 버튼 및 Space 키: 낮은 장애물, 축구 골대, 놀이터 울타리 등을 뛰어넘기
- 3600×2200 대형 운동장
- 본관 1~5층 내부: 교실, 복도, 도서관, 과학실, 컴퓨터실, 음악실 등
- 운동장 ↔ 1층, 1~5층 계단 이동
- 게임 시작 후 매 1분마다 붕어빵 아이템 등장
- 붕어빵 획득 시 부스터 충전, 버튼 사용 시 10초간 도망팀 이동속도 2배
- 교사 화면에서 운동장/1~5층 탭 전환 및 각 층 인원 확인
- 태블릿/휴대폰 방향키 길게 누르기 시 복사/찾아보기/선택 메뉴 방지
- 지원 브라우저에서는 Screen Wake Lock을 사용해 게임 중 자동 화면 꺼짐도 최대한 방지

## 조작

- 이동: 방향키 또는 W/A/S/D
- 얼음: I 또는 `얼음!` 버튼 (도망팀)
- 점프: Space 또는 `점프` 버튼
- 부스터: B 또는 붕어빵 획득 후 나타나는 `부스터` 버튼

## Render 무료 배포

`render.yaml`은 `plan: free`입니다.

Build Command:

```text
npm install
```

Start Command:

```text
npm start
```

Health Check:

```text
/health
```

## 참고

게임방과 플레이 상태는 Render 서버 메모리에 있습니다. 휴대폰의 단순 화면 꺼짐/네트워크 재연결은 자동 복구하지만, Render 인스턴스 자체가 재시작되어 서버 메모리가 초기화되면 기존 방은 복구할 수 없습니다. 수업 중에는 교사 화면을 켜둔 상태로 사용하는 것을 권장합니다.
