# 탄벌초 얼음땡 V4

무료 GitHub + Render 배포용 실시간 웹게임입니다.

## 주요 기능
- 교사용 방 만들기 + 학생용 QR 입장
- 최대 100명 동시 접속 구조
- 술래 수 / 게임 시간 설정
- 운동장 + 본관 1~3층 맵
- 남자/여자 캐릭터 선택
- 여자 캐릭터는 치마 교복, 남자 캐릭터는 교복 스타일
- 얼음 / 구출 / 아웃 / 유령 상태
- 휴대폰 화면이 꺼졌다 켜져도 자동 복귀 시도
- 점프, 붕어빵 아이템, 10초 부스터
- 술래도 붕어빵을 먹으면 부스터 사용 가능
- 얼음 상태에서 같은 팀에게 위치 구조 요청 전송
- 플레이어 공지 피드 및 효과음

## 실행
```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속
