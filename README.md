# 탄벌초 얼음땡 V6

GitHub + Render 무료 배포용 실시간 웹게임입니다.

## V6 변경사항
- 붕어빵은 게임 중 **딱 한 번만**, 전체 게임 시간의 정확히 절반 시점에 등장합니다.
  - 3분 게임 → 1분 30초
  - 4분 게임 → 2분
  - 5분 게임 → 2분 30초
- 붕어빵은 등장 후 **20초 동안만** 맵에 남고, 먹지 않은 붕어빵은 자동으로 사라집니다.
- 캐릭터가 왼쪽을 볼 때 몸만 좌우 반전되고, **닉네임과 '술래/유령' 글자는 더 이상 뒤집히지 않습니다.**

## 기존 주요 기능
- 교사용 방 만들기 + QR 학생 입장
- 운동장 + 본관 1~3층
- 술래/도망팀 구분 캐릭터
- 얼음/구출/아웃/유령 이동
- 교사 화면 얼음 인원 표시
- 실시간 소식은 팝업이 아닌 채팅/피드에 표시
- 점프, 붕어빵, 10초 부스터
- 휴대폰 재접속 복구

## 로컬 실행
```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속
